TOEIC 영단어장 - 개발 보고서

1. 프로젝트 개요

TOEIC 시험 대비를 위한 영단어 학습 웹 애플리케이션을 개발하였다. 별도의 서버나 프레임워크 없이 순수 HTML/CSS/JavaScript만으로 구현하여, HTML 파일 하나만 브라우저에서 열면 즉시 학습이 가능하도록 설계하였다. PC용과 모바일용 두 가지 버전을 제공한다.

2. 개발 과정 요약

2.1 데이터 수집 및 가공

  1. dokjongban.com에서 제공하는 TOEIC 단어 PDF(toeic_vocab.pdf)로부터 단어 데이터를 추출
  2. 추출한 데이터를 JSON 형식(toeic_words.json)으로 정리 (영단어, 한국어 뜻, IPA 발음 기호)
  3. gen_pronun.py 스크립트를 작성하여 IPA 발음 기호를 영어식 발음 표기(respelling)로 자동 변환

2.2 애플리케이션 개발

  1. Python 빌드 스크립트(build_toeic.py, build_toeic_mobile.py)를 작성하여 JSON 데이터를 HTML 내부에 임베딩
  2. 단어 목록, 타이핑 학습, 테스트 모드 등 핵심 기능 구현
  3. Free Dictionary API와 MyMemory Translation API를 연동한 사전 조회 기능 추가
  4. 다크/라이트 모드, 반응형 UI 등 사용자 편의 기능 구현

3. 주요 기술적 결정 및 해결 과제

3.1 PDF 파싱을 통한 단어 추출

원본 TOEIC 단어 데이터는 PDF 형태로 제공되었다. PDF에서 영단어, 한국어 뜻, 품사 정보를 정확히 추출하여 구조화된 JSON 데이터로 변환하는 과정이 필요했다.

3.2 단일 HTML 파일 아키텍처

서버 없이 동작하는 것을 핵심 설계 목표로 삼았다. Python 빌드 스크립트가 JSON 단어 데이터를 JavaScript 변수로 변환하여 HTML 파일 내부에 직접 삽입한다. 이를 통해 HTML 파일 하나만으로 완전한 애플리케이션이 동작하며, 별도의 웹 서버나 빌드 도구가 필요 없다.

3.3 테스트 모드의 동의어 감지

한→영 타이핑 테스트에서 사용자가 정답과 다른 단어를 입력했더라도, 해당 단어가 단어 목록에 존재하고 뜻(한국어 키워드)이 유사한 경우 동의어로 인정하는 로직을 구현하였다. 한국어 뜻에서 키워드를 추출하고, 두 단어 간 키워드가 겹치는지 비교하여 판별한다.

3.4 영→한 테스트의 4지선다 구현

영→한 테스트는 타이핑이 아닌 4지선다 객관식으로 설계하였다. 영단어를 보고 올바른 한국어 뜻을 4개의 선택지 중에서 고르는 방식이다. 오답 선택지는 전체 단어 목록에서 무작위로 추출하여 자연스러운 난이도를 유지한다.

3.5 카테고리 시스템

각 단어를 학습완료(learned), 헷갈림(confused), 미학습(none) 3가지 상태로 분류할 수 있다. 카드를 클릭하면 상태가 순환하며, 학습 및 테스트 시 특정 카테고리의 단어만 선별하여 집중 학습이 가능하다.

3.6 localStorage를 활용한 데이터 영속성

서버가 없으므로 모든 사용자 데이터를 브라우저의 localStorage에 저장한다. 저장 항목은 다음과 같다:

  • toeic_word_status: 각 단어의 학습 상태 (learned/confused/none)
  • toeic_settings: 학습 설정 (반복 횟수, 순서, 뜻 표시 방식 등)
  • toeic_custom_words: 사용자가 추가한 커스텀 단어
  • toeic_theme: 다크/라이트 모드 설정

3.7 IPA 발음 표기 생성

gen_pronun.py 스크립트에서 IPA(국제 음성 기호)를 영어 사용자에게 친숙한 발음 표기(respelling)로 변환한다. 이중 모음, 장모음, 파찰음 등을 우선 매칭하고, 강세 음절은 대문자로 표기하여 직관적인 발음 안내를 제공한다.

3.8 무료 API 연동 (사전 + 번역)

외부 API를 활용하여 추가적인 학습 정보를 제공한다:

  • Free Dictionary API (dictionaryapi.dev): 영영 사전 정의, 품사, 예문 조회
  • MyMemory Translation API (mymemory.translated.net): 영어 정의를 한국어로 자동 번역

두 API 모두 무료이며 API 키가 필요 없어, 단일 HTML 파일 아키텍처에 적합하다.

3.9 반응형 디자인 (PC/모바일)

PC용과 모바일용을 별도의 HTML로 분리하여 각 환경에 최적화하였다:

  • PC용 (toeic-typing.html): 넓은 화면에 맞는 그리드 레이아웃, 상단 탭 네비게이션
  • 모바일용 (toeic-mobile.html): 하단 탭 네비게이션, 터치 최적화 UI, safe-area 대응, 스크롤 스냅 등 모바일 UX 고려

5. 향후 개선 가능 사항

  • PWA (Progressive Web App) 전환: Service Worker를 추가하여 오프라인 설치 및 사용 지원
  • 단어 확장: 현재 수록된 단어 외에 추가 TOEIC 빈출 단어 확대
  • 학습 통계 대시보드: 일별/주별 학습량, 정답률 추이 등의 통계 시각화
  • 간격 반복 학습 (Spaced Repetition): 에빙하우스 망각 곡선 기반의 자동 복습 스케줄링
  • 데이터 내보내기/가져오기: 학습 데이터를 JSON으로 백업 및 복원하는 기능
  • 예문 학습 모드: 단어를 문장 속에서 학습할 수 있는 모드 추가
  • PC/모바일 통합: 단일 HTML로 반응형 디자인 통합
